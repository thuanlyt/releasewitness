03The assurance loop

Fast agents.
Exact release evidence.

ReleaseWitness does not need to supervise the coding session. It records what QA verified and checks whether the source still matches when you are ready to ship.

See the gate in operation →
  1. 01
    Implement

    Your native coding runtime plans, delegates and edits with its own agents and worktrees.

  2. 02
    QA

    relwit qa runs configured checks and fingerprints the exact release-source content.

  3. 03
    Drift check

    relwit gate fails when the passing QA record no longer matches the current source.

  4. 04
    Release

    --require-clean adds the clean Git-tree requirement; deployment authority stays with you.

04Measured, not assumed

Why the product got smaller.

The repository-backed study used 56 real Claude Code sessions. Full RelWit supervision produced the same final correctness and recovery outcomes, while costing 1.9–4.8× more per task and taking 1.8–5.6× longer in the tested fixture.
